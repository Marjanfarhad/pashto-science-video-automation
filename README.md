# Pashto science video automation

Online rendering from approved Pashto scripts using Edge TTS and FFmpeg.

Status: deployment in progress. TikTok is not connected. No automatic posting or recurring schedule is active.

Only standard GitHub-hosted runners in a public repository are intended. Do not enable paid runners or paid overage.

The first pilot covers why the sky appears blue. Source: https://science.nasa.gov/ems/03_behaviors/
